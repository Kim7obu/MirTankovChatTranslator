# 전차 채팅 용어 사전 (검수본 v0.1)

러시아어 인게임 채팅 → 한국어. 기계번역이 못 잡는 것만 모았다.

- `?` = 확신 낮음. 검수 요망
- `변형` = 같은 뜻으로 쓰이는 다른 표기 (오타·격변화 포함)
- 게임 UI 용어가 아니라 **채팅에서 실제 쓰는 말** 기준

## 검수 결과 (2026-09-05 확정)

1. **`бб` → 은탄으로 고정.** 작별인사(bye-bye) 용법은 포기한다.
2. **`топ` → "탑".** 티어("탑방")와 최종부품("탑건") 양쪽 문맥을 한 단어로 덮는다.
3. **욕설은 순화하지 않는다.** 완곡어로 바꾸거나 걸러내는 로직을 넣지 않고 원문 세기 그대로 옮긴다.
   서버가 이미 `***` 로 가려 보내는 것은 그대로 통과시킨다 (키릴이 없어 번역 대상에서 자동 제외된다).
4. **철갑탄이 아니라 "은탄".** 채팅은 게임 UI가 아니라 커뮤니티 용어를 따른다.
